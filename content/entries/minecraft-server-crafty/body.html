Paper is a high-performance fork of the vanilla server that supports plugins. Crafty Controller is a web panel for running Minecraft servers. It handles starting and stopping, the console, scheduled tasks, backups and server settings, so day-to-day running doesn't need an SSH session.

The server runs in its own VM on the third Proxmox host, away from the cluster that serves this site.

Exposure

What's reachable, and from where

  • Crafty's panel is LAN-only. A web panel that can run commands on a server is the last thing to put on the internet, so it isn't published anywhere.
  • The game port is LAN-only too, for now. This site goes out through a Cloudflare Tunnel because the ISP's DS-Lite setup makes port forwarding impossible (see Going live via Cloudflare Tunnel). A tunnel like that carries web traffic, but a normal Minecraft client can't connect through it. Opening the server to friends outside the house needs a TCP relay. That's a separate piece of work.

Live status without a new hole

The projects page shows whether the server is up, how many players are on, the version and the ping. The hub on UbuntuServ asks the server over the home network using the standard Server List Ping, the same request the multiplayer screen sends. The result is cached for 30 seconds. Only those four values are published: no address, player names or MOTD.
